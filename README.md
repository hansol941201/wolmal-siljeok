# 월말실적정리

한솔 POUR 공사실적 통합관리 화면입니다.

## 보는 방법

### 1. 주소로 바로 보기 (권장)

**https://hansol941201.github.io/wolmal-siljeok/**

내려받을 필요 없이 주소만 누르면 열립니다. 화면을 고쳐 새로 올리면
**이 주소가 늘 최신을 보여 줍니다.** 링크를 한 번만 알려 두면 됩니다.

### 2. 파일로 받아 보기

목록에서 `POUR공사실적관리.html` 을 누른 뒤 오른쪽 위
**Download raw file** 을 누릅니다. 내려받은 파일을 더블클릭하면 열립니다.
인터넷이 없어도 되고, 메일이나 메신저로 그 파일만 보내도 됩니다.

## 들어 있는 기능

| | |
|---|---|
| ＋ 새 공고 | K-APT 공고문에서 확인되는 항목만 입력합니다 (공고번호 포함) |
| 낙찰로 변경 | 같은 현장에 시공사·낙찰일·낙찰금액·협약사 여부·협약서번호를 더합니다 |
| 상세·수정 | ① 공고 정보 / ② 낙찰 정보 두 구획으로 한 현장의 이력을 봅니다 |
| 특허 내역 | 현장에 든 특허를 하나씩 보여 줍니다 (POUR · DO · CNC · 타사공법) |
| 상태 탭 · 검색 | 전체 / 낙찰 / 공고 / 재공고(유찰) |

한 현장을 공고로 등록한 뒤 낙찰로 바꿔도 **새 줄이 생기지 않고 같은 줄에
정보가 쌓입니다.** DO 공법과 CNC 는 자사 계열이지만 POUR 공법과는 따로
구분됩니다.

## 자료

**예시 자료 7건**만 들어 있습니다. 실제 공사실적은 담겨 있지 않습니다.

화면에서 입력한 내용은 **보는 사람의 브라우저에만** 남습니다. 다른 사람에게
전달되지 않고, 이 파일이나 저장소가 바뀌지도 않습니다. 여러 사람이 각자
눌러 봐도 서로 영향을 주지 않습니다.

## 이 파일은 어디서 오는가

손으로 만든 파일이 아닙니다. 원본 코드에서 만들어 낸 결과물입니다.

- 원본: `hansol941201/shin` 저장소의 `pour-integration/`
- 만드는 명령: `python3 pour-integration/scripts/build-preview.py`

그러므로 **이 파일을 직접 고치지 마세요.** 고쳐야 할 것이 있으면 원본을
고친 뒤 다시 만들어 여기에 올립니다.

`index.html` 과 `POUR공사실적관리.html` 은 같은 내용입니다.
앞의 것은 주소로 보기 위한 것이고, 뒤의 것은 내려받기 좋은 이름입니다.
