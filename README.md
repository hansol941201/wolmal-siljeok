# 월말실적정리

한솔 POUR 공사실적 통합관리 화면입니다.

## POUR공사실적관리.html

파일을 내려받아 **더블클릭**하면 브라우저에서 바로 열립니다.
로그인도, 인터넷 연결도 필요 없습니다. 메일이나 메신저로 이 파일만
보내면 받는 사람도 그대로 열어 봅니다.

**내려받는 법** — 위 목록에서 `POUR공사실적관리.html` 을 누른 뒤
오른쪽 위 **Download raw file** 을 누릅니다.

### 들어 있는 기능

| | |
|---|---|
| ＋ 새 공고 | K-APT 공고문에서 확인되는 항목만 입력합니다 (공고번호 포함) |
| 낙찰로 변경 | 같은 현장에 시공사·낙찰일·낙찰금액·협약사 여부·협약서번호를 더합니다 |
| 상세·수정 | ① 공고 정보 / ② 낙찰 정보 두 구획으로 한 현장의 이력을 봅니다 |
| 특허 내역 | 현장에 든 특허를 하나씩 보여 줍니다 (POUR · DO · CNC · 타사공법) |
| 상태 탭 · 검색 | 전체 / 낙찰 / 공고 / 재공고(유찰) |

한 현장을 공고로 등록한 뒤 낙찰로 바꿔도 **새 줄이 생기지 않고 같은 줄에
정보가 쌓입니다.** DO 공법과 CNC 는 자사 계열이지만 POUR 공법과는 따로
구분됩니다.

### 자료

**예시 자료 7건**만 들어 있습니다. 실제 공사실적은 담겨 있지 않습니다.

화면에서 입력한 내용은 그 브라우저에만 남습니다. 다른 사람에게 전달되지
않고, 파일 자체가 바뀌지도 않습니다. 지우려면 브라우저 사이트 데이터를
지우면 됩니다.
